# 프레스 제품 견적서 작성기
- URL: /resources/press-product-quotation/
- 기존 금형 견적서와 동일한 CSS, Canvas PDF 방식. 고객 제출용 PDF와 내부 원가산출서 PDF 분리.
- 생산 방식 2종은 견적 조건으로 기록. 여러 공정 입력은 지원하지 않음.
- 생산량은 정지·불량을 반영한 양품/시간. 별도 효율·불량률 재가산 없음.
- 전개 치수는 작성자 입력. 단열 배치만 지원. 확정 폭·피치도 단열 조건으로 검증.
- 금형비 배분/스크랩 차감은 기본 해제.
- 입력은 전용 localStorage 키에 저장. JSON 편집 파일은 값과 가격 출처 스냅샷 포함. 기존 금형 작성기 데이터와 분리.
- DB: data/press-product-defaults.json (UI 사용), data/press-material-prices.json (원문 가격 조사 기록).
- 2026 최저임금 10,320원/시간. 갱신 시 wage와 화면의 연도 설명도 함께 수정.
- 국내 톤수별 공개 시장 임률은 확인되지 않음. 톤수별 제안값은 인건비 제외 QDM 예산값이며 조사 자료의 실거래가로 표시하지 말 것.
- 소재의 예산값과 공개가는 구분. 해외 USD 가격은 국내 매입가로 자동 환산하지 않음.
- 초기 잔폭 규칙은 금형 설계 기준이 아닌 수정 가능한 예산 가정. 크기·캐리어·형상 자동 판정 없음.
- 내부 원가: (소재비−스크랩)+(인건비+설비비)/생산량+준비비/로트수량+선택 금형비/배분수량+기타.
- 관리비는 직접원가에 가산. 이익은 관리비 포함 원가에 가산. 단가 올림 후 수량을 곱하고 VAT 10% 반올림.
- 검증: node tests/press-product-cost.test.cjs
